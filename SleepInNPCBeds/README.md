# Sleep in NPC Beds（睡 NPC 的床）

一个 SMAPI mod：可以在任意 NPC 的床上睡觉。走到床边（床脚的空位）会弹出“要睡觉吗？”，确认后与睡自家床完全一样：结束当天、进入结算、自动存档，第二天早上在你睡下的那张 NPC 床上醒来。

## 功能

- 自动识别所有 NPC 的床：根据每个 NPC 的日程数据解析出“bed”路线（也就是游戏自己认定的睡觉位置），不依赖写死的坐标。
- 完全复用原版的睡觉/存档流程：结束当天、收益结算、自动保存全部照常。
- 醒来时就在 NPC 床上，而不是被送回农舍。
- 兼容带标准日程和睡觉动画的自定义 NPC（如大型扩展 mod 的新村民）。
- 单人和多人（主机）都可以用；多人时仍按原版规则需要其他玩家一起入睡。

## 安装

1. 安装 SMAPI 4.x，并确认游戏能通过 SMAPI 正常启动。
2. 把编译好的 `SleepInNPCBeds` 文件夹放进 `Stardew Valley/Mods/`。
3. 用 SMAPI 启动游戏，进入任意 NPC 家里，走到床边即可睡觉。

## 从源码编译

需要 .NET SDK（6/8/9 均可）和星露谷 1.6 游戏本体。

在 `SleepInNPCBeds` 目录下运行：

```powershell
dotnet build -c Release
```

如果游戏没有装在常见位置，额外指定游戏目录：

```powershell
dotnet build -c Release -p:GamePath="D:\SteamLibrary\steamapps\common\Stardew Valley"
```

构建成功后会自动把 mod 复制到游戏的 `Mods` 目录，并在 `bin/Release/net6.0/` 里生成可直接分享的 zip 包。
也可以直接运行项目里的 `build.ps1`（可选传入 `-GamePath` 参数）。

## 原理

游戏里“床”是由地图格子的两个属性控制的：

- `Bed T`：站在该格视为“在床上”，决定起床位置。
- `TouchAction Sleep`：走到该格时弹出睡觉确认，然后走原版的 `startSleep` → 新的一天 → 自动保存。

本 mod 从每个 NPC 的默认日程中解析出“bed”路线（每晚睡觉的位置），把这些格子补上上述两个属性，其余全部交给原版逻辑，因此存档行为和自家床完全一致。

## 已知限制

- 只识别游戏数据里确实“上床睡觉”的 NPC（日程终点带 `_sleep` 睡觉动画）；没有床的 NPC（如矮人、克罗布斯、法师、桑迪等）自然没有可睡的位置。
- 结婚后的配偶睡在农舍的床（原版功能），不会被重复标记。
- 若某个床位格本身被地图碰撞挡住、玩家无法站上去，则该格不会触发睡觉（原版床脚格都是可站的，NPC 家通常也一样）。
- 目前不需要配置文件；默认总是弹出原版的确认框，避免误触。
